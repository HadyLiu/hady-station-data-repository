# 桌面预览与应用程序快捷方式

> 适用：Ubuntu GNOME。典型场景：把解压式的软件（不经过 apt 安装）挂到桌面和任务栏。

## 1. 文件快速预览

GNOME 自带 Sushi 预览器，但默认不装：

```bash
sudo apt install -y gnome-sushi
```

装完在文件管理器里选中文件按**空格**，直接预览文档、图片、音视频，不用打开对应程序。

## 2. 为什么桌面快捷方式能点，任务栏图标却是空白

这是两个互相独立的机制：

| 机制 | 作用 | 生效范围 |
| --- | --- | --- |
| `~/Desktop/xxx.desktop` | 双击启动 | 只有桌面 |
| `~/.local/share/applications/xxx.desktop` | 注册为「应用」 | 应用列表、任务栏、`gtk-launch` |

任务栏**只认** `~/.local/share/applications/` 里的那条记录。图标也是从这条记录里的 `Icon=` 取的，跟桌面文件无关。

## 3. 桌面启动项

`~/Desktop/simplicity-studio.desktop`：

```ini
[Desktop Entry]
Version=1.0
Type=Application
Name=Simplicity Studio
Comment=Silicon Labs Integrated Development Environment
Exec=/bin/sh -c "export GDK_BACKEND=x11; export GDK_SCALE=1; unset GDK_DPI_SCALE; exec /home/<user>/.silabs/slt/installs/archive/<版本>/SimplicityStudio-6/studio"
Path=/home/<user>/.silabs/slt/installs/archive/<版本>/SimplicityStudio-6
Icon=/home/<user>/.silabs/slt/installs/archive/<版本>/SimplicityStudio-6/icon.xpm
Terminal=false
Categories=Development;IDE;
StartupWMClass=Simplicity Studio
StartupNotify=true
```

要点：

- `Exec` 用 `/bin/sh -c "..."` 包一层，才能在里面设环境变量再 `exec`。
- `Path` 必须设，否则程序按「当前目录」找资源会失败。
- 首次保存后要 `chmod +x` 并**右键 → 允许启动**（GNOME 对桌面文件默认不可执行）。

## 4. 让任务栏正确显示图标

三步，缺一不可：

1. **图标转 PNG 并按尺寸放好**（`.xpm` 任务栏不一定认得）：

   ```bash
   convert icon.xpm ~/.local/share/icons/hicolor/256x256/apps/simplicity-studio.png
   gtk-update-icon-cache ~/.local/share/icons/hicolor
   ```

2. **写应用记录** `~/.local/share/applications/simplicity-studio.desktop`，内容同上面的桌面文件，但 `Icon=` 只写图标名（不带路径、不带扩展名）：

   ```ini
   Icon=simplicity-studio
   ```

3. **让窗口类名对得上**。任务栏按窗口的 `WM_CLASS` 匹配 `.desktop` 里的 `StartupWMClass`，对不上就用默认图标。确认实际类名：

   ```bash
   xprop WM_CLASS        # 点一下目标窗口
   ```

   - 值对不上 → 改 `StartupWMClass` 为实际值；
   - 程序自己声明了别的类名 → 在 `studio.ini` 里加 `-name "Simplicity Studio"` 强制统一。

最后 `update-desktop-database ~/.local/share/applications` 刷新缓存，注销重登生效。

## 5. 坑

| 现象 | 原因 |
| --- | --- |
| 双击没反应 | 文件没有执行权限，或 GNOME 未「允许启动」 |
| 任务栏图标是问号 | `Icon=` 写了完整路径而非图标名 |
| 图标能显示但点了不聚焦/另开一个图标 | `StartupWMClass` 与真实 `WM_CLASS` 不一致 |
| 高分屏下界面小得离谱 | 需要 `GDK_SCALE` / `GDK_DPI_SCALE`，见上面 `Exec` 里的写法 |
